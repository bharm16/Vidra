## Phrase suggestion fetch and application

Prefer these independent transports over the legacy progression/fetch/apply owner. Parameter aliases below are **file-private**, although the functions are exported; derive their type with `Parameters<typeof fn>[0]` if necessary.

```ts
fetchEnhancementSuggestions(params: FetchEnhancementSuggestionsParams):
  Promise<EnhancementSuggestionsResponse>;
// Required: highlightedText, contextBefore, contextAfter, fullPrompt, inputPrompt.
// Optional: brainstormContext, metadata { startIndex?, category?, confidence?, quote? },
// allLabeledSpans, nearbySpans, editHistory, signal.

fetchCustomSuggestions(params: FetchCustomSuggestionsParams): Promise<SuggestionItem[]>;
// Required: highlightedText, customRequest, fullPrompt.
// Optional: contextBefore, contextAfter, metadata, signal.

postEnhancementSuggestions<TSuggestion = string>(
  payload: EnhancementSuggestionsRequest,
  options?: EnhancementSuggestionsFetchOptions,

Existing payloads do not establish draft/revision/authorization or qualified action/model/input identity; that binding belongs in the new feature transaction and, where required, its API contract.
