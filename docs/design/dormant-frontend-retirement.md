# Dormant frontend retirement

**Backend status, 2026-10-09:** This remains the October 8 frontend/design adoption record. Its retained-backend statements are historical: the selected dormant registrations/endpoints have now been retired. Current ownership and saved-record/recovery compatibility live in [CONTEXT.md](../../CONTEXT.md) and the [cleanup record](../audits/2026-10-09-frozen-separation-plan.md).

The owner amended #177 on 2026-10-08: remove the live frontend controls and routes for every frozen/dormant workflow; keep backend routes and services available and mark them dormant. The [JSON ledger](dormant-frontend-retirement.json) records each registration, its backend counterpart and the exact file removal list.

`dormant_registered` is the backend's product maintenance status, not an instruction to unregister or enable it. Existing server gates remain unchanged. This frontend cleanup changes no server file, shared contract, persisted record or worker registration.

| Retired frontend workflow                                                                                        | Backend retained as dormant                                                              | Active behavior retained                                                                   |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Named character/style/location/object library, editor, detected assets and @ autocomplete/validation             | `/api/assets/*`, asset CRUD/resolution/validation services                               | Explicit uploaded/reference images, persisted media ids and ordinary visible words         |
| Camera-motion picker, depth preview and FrameAnimator                                                            | `POST /api/motion/depth`, depth service; existing convergence-media gate                 | Camera direction written as ordinary visible words and inline phrase suggestions           |
| Continuity/sequence surfaces, shot hydration, shot-bound editor/model/version writers and continue-scene actions | `/api/sessions/continuity`, shot/scene-proxy/settings/style-reference routes             | Generic authoring session loading, words versions, take history and durable media handoffs |
| Storyboard, detected-character keyframe approval and face-swap preview                                           | `/api/preview/generate/storyboard`, `/api/preview/face-swap`, planner/character services | Explicit first frames, reference selection, ordinary video generation and clip extension   |
| Model analysis/recommendation and the sample showroom                                                            | `/api/model-intelligence/recommend`, `/api/model-intelligence/track`                     | Manual supported-model selection and capabilities                                          |
| Coherence issue panels/markers/popovers and their post-suggestion request callback                               | `/api/enhancement/prompt-coherence`                                                      | Inline suggestions, highlight updates, edits and undo; active optimizer intent checks      |
| Old improver/brainstorm forms and category accordion                                                             | No separate backend retirement                                                           | Optimize/expand, span labeling and inline refinement                                       |
| Pricing, billing, invoices, balances and credit UI subscriptions/events                                          | `/api/payment/*`, payment/credit services and existing registrations                     | Real account identity/security, active free-intake admission and backend spending bounds   |

Frozen frontend routes now reach the normal 404 instead of redirecting into a supported workspace. The old `VITE_FEATURE_*` values cannot remount these features. WorkspaceSessionContext loads an ordinary session and no longer imports a continuity wire client or publishes continuity actions.

The old catalog's mixed “Shared utilities and dormant controls” heading is not a blanket deletion list. DownloadSelectedImage and UnattachedTakeBadge are active download/recovery controls. Likewise, historical camera metadata remains readable in saved records, image/video media URL resolution remains active, and the standalone live editor, Studio, Sketch and their explicit acceptance/recovery paths remain registered.
