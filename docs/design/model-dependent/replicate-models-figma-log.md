# Native model capabilities — Figma log, October 19, 2026

Twelve Replicate models were added as additions only; no existing model was removed or changed. On the server every documented setting of each model is offered through the workflow capability profiles (17 new profiles), and Studio gained two roster entries. The app UI shows only part of this. This log lists each capability the app does not yet expose, so it can be designed in Figma next and then implemented.

Source of truth for what each model offers: `server/src/services/creation-requests/replicate-models/` (one definition per profile, with the exact Replicate input mapping). Spend ceilings: `server/src/services/creation-requests/execution/workflowSpendPolicy.ts`.

## Engineering follow-ups (not Figma)

- **Per-setting spend reservations.** Reservations use each profile's maximum; reserving by the chosen resolution/duration would let drafts cost what they cost.
- **Replay seam.** The native model runner makes live calls and is disabled in replay mode; add a record/replay seam like the image-preview one before journeys depend on these models.
- **Mask upload.** Persist the area canvas as a mask media version and bind it as the `mask` input (S6).
- **Larger pictures.** Vidra verifies pictures up to 40 MP, so bigger Topaz upscales are refused before spend.
- **Long transcripts.** Transcripts are text outputs (32,000 characters), so input is capped at 15 minutes; longer audio needs a stored caption file.
- **Studio GPT Image edits.** Studio sent GPT Image source pictures as `image_input`; the models read `input_images`. Fixed with the Sunburst entry, which shares the code path, so GPT Image 2 edits now receive their pictures too.

## Assumptions to confirm on the first live run

- Wan 3 sound: the Replicate page doesn't mention audio (profile says "unknown"). Pricing conflicts between the readme ($0.20/s at 1080p) and billing ($0.10/s); the higher is reserved.
- Gemini Omni: output length (~10 s observed) and the reference limit (3 assumed).
- Eleven v3: 3,000-character request limit; whether continuity text is billed.
- Luma Reframe: the input schema says 10 s while the readme says 30 s; 10 s is offered.
- Topaz: billing is in $0.08 units while the published guides use older dollar figures; ceilings scale the guides up.
- No provider was called during this change; free-testing spend is unchanged until someone runs these models.
