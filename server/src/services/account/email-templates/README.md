# Account action email templates

`renderAccountActionEmail` renders retained Figma T01 (`971:94732`, verification) and T02 (`971:94745`, password reset) as HTML and plaintext. The HTML uses presentation tables, inline typography and colors, and the existing Figtree font assets. It has no network or sending side effects.

Pass the recipient address and the complete HTTPS action link generated by the Firebase Admin SDK. The renderer validates and escapes inserted values. `siteOrigin` defaults to `https://vidra.app`; when configured, it must be an HTTPS origin and supplies the existing public legal/help routes and font asset URLs. It does not restrict the action link to that origin because Firebase can use a separate authorized action domain. The sending service must supply the trusted Admin-generated link.

These templates are **not connected to production email delivery**. Current client calls use Firebase `sendEmailVerification` and `sendPasswordResetEmail`, whose Google-sent templates have limited customizability. [Firebase's custom email action link workflow](https://firebase.google.com/docs/auth/admin/email-action-links) requires an Admin-generated action link and a separately configured email delivery service. Sender credentials, domain authorization, rate limits, request abuse protection, delivery, and received-email behavior require their own integration and validation before switching transports.

The 600 × 473 local browser previews prove the retained layout with Figtree loaded. Mail clients that suppress webfonts will use Arial; delivered-email font support, dark-mode overrides and rendering across mail clients remain unverified. No provider-console settings are changed by this folder.
